## 测试组织与循环

- 后端沿用 Vitest，使用真实 SQLite；HTTP 服务测试沿用现有公共 API 测试方式。协议传输测试启动本地服务并使用真实网络连接。
- 数据是否持久化、授权是否保留、审计和统计是否正确，均通过相应公开 API 验证，不直接查询数据库作为断言。
- 数据库不可写、网络中断和时间等故障仅在系统边界构造；不 mock 平台内部协作者或测试私有函数。
- 控制台关键流程使用浏览器端到端测试。前后端类型检查和构建作为配套检查，不替代行为验证。
- 一次只做一个行为切片：写一个失败测试并运行确认失败 → 实现最少代码 → 运行确认通过 → 完成对应检查并提交。
- 测试数据库、服务器、连接、计时器和浏览器按测试生命周期释放；正式测试夹具归入项目测试目录。
