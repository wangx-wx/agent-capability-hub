内部引用补充：支持递归 `$anchor` 与 JSON Pointer 指向同一 schema，归一化为单个本地定义，嵌套约束仍经真实试调用验证。带 `$id` 作用域或动态引用的 schema 明确提示暂不支持，避免改变引用含义。导入/试调用回归与类型检查通过。

原生发现完整性：使用官方 SDK 的公开 request 获取完整分页，显式检查 cursor 循环及 header 声明；非法工具导致同步失败，保留旧目录，避免 SDK 静默过滤被误当删除。发现、SSE、重连回归及类型检查通过。

同步时序：每服务只保留最新预览，开始新发现即使旧预览失效；迟到发现返回 409。服务修改/删除同时清理预览，目录 fingerprint 仍保护确认。受控并发发现、改名及在途调用回归、类型检查通过。

服务类型保护：管理 API 禁止在登记后把 MCP/REST 类型互换，以免既有工具错误切换执行适配器；配置预览和保存均拒绝。公共 API 回归通过。

JSON 媒体类型：导入保留所选 `application/*+json`（例如 merge-patch），REST 执行按保存的类型发送，管理员静态头仍优先。真实下游媒体类型、正文、重导入回归与类型检查通过。

请求方向 schema：同一对象的 allOf/引用分支共享 readOnly 名称，删除对应 required 而保留其他必填字段；引用定义按请求上下文区分，递归引用仍不无限展开。组合、递归、3.0/3.1 回归与类型检查通过。

REST 操作身份：手工创建及 PATCH/PUT 禁止与同服务其他工具重复 HTTP 方法+路径，避免重导入匹配歧义。身份、工具生命周期、重导入与类型检查通过。

路径编码：点/双点独立路径段不能被 WHATWG URL 原样表达，运行时明确拒绝，不误向规范化后的地址发请求；真实下游无请求和正常路径编码回归通过。

部署绑定：API_HOST 默认为 0.0.0.0，可选择部署所需地址；独立启动进程绑定 IPv6 指定地址并访问健康检查，退出清理进程和内存数据库。类型检查通过。
